Four dimensions, one component, zero re-authoring

Every control below is the same .ds-button. The four selectors above each touch a different layer of the token graph — brand swaps tier-1 ramps, mode flips color-scheme to pick the light-dark() slot, contrast overrides the semantic colour block, density rescales tier-2 spacing. Because each dimension owns a different layer, they compose instead of multiplying: there is no dark × dusk × compact stylesheet anywhere — that combination is computed live.

Variants — the group segment is dropped from the hook name; specificity picks the winner.
Sizes — heights carry the WCAG floor. Drag density to ×0.6: the small button stops shrinking at 24px while padding keeps compacting.
External override — the consumer reaches in and reskins one instance, no new token required: .override { --ds-button-bg: rebeccapurple }.
Switch to dark and watch the primary button's text flip from white to near-black. That is color.text.on-accent doing its one job — the single token most systems get wrong, and the reason a naive palette invert breaks.
State layers — hover / focus / press these. Every row is .ds-interactive: one currentColor overlay at a per-state opacity, a single active layer (never summed), plus an independent focus ring. Try dark, dusk, and high-contrast — the same overlay tracks the content colour of each context.
